# 悬浮窗

悬浮窗是听会时看的那一块，不是聊天，也不是第二套设置。

## 形态

收起时窗口大约 600×54，贴在屏幕上方，可以拖动。上面有开始/结束、当前行业、防截屏、打开设置。

点开始后先选择行业和远程/现场，再开始听。行业没选好不能开始。预设和「其他」自填见 [PRD](./PRD.md)。选择会记住。

正在听、还没有术语时，仍然是这条细栏：状态（等待语音、正在听或转写异常）加上行业名。没有助手在说话。

出现术语后窗口变高，宽度大约 920。最新术语大约 64px，解释大约 28px，深色高对比，方便压在会议窗口上。本场较早的术语留在下面的小列表里。结束聆听后卡片清空，下一场重新计算。

设置从菜单栏打开独立窗口。会议进行中不在悬浮窗里再铺一页设置。

## 窗口行为

macOS 上收起的岛是不抢焦点的 NSPanel，可以跨 Space。高度超过 54 时按展开窗口处理，方便看清术语卡。防截屏是 `contentProtected` 开关，不承诺所有会议软件都看不到。见 [STEALTH_AND_SCREEN_CAPTURE.md](./STEALTH_AND_SCREEN_CAPTURE.md)。
