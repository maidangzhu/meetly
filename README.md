# Meetly

Meetly 在你听一场会的时候，用大字解释当场出现的行业术语。

远程会议同时听系统声音和麦克风，现场会议只听麦克风。转写里出现当前行业的缩写或行话时，弹出一张高对比的术语卡。普通句子保持安静。同一个术语在这一场里只解释一次。

开始前选择行业。预设包括 CRO / 临床研究、IT、建筑、电商、金融、医疗、制造、教育，也可以自己填写。同一个缩写按所选行业解释：在 CRO / 临床研究里，CTA 是临床试验助理；在电商里，CTA 可以是行动号召。如果当前行业里仍有两种说得通的意思，不弹出卡片。

语音转写和语言模型使用你自己的 API Key，配置留在菜单栏的设置窗口里。
